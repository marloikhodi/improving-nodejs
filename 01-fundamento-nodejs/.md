"node:" informa que o pacote é nativo do node

- HTTP
- Método HTTP
- URL

métodos principais:
GET, POST, PUT, PATCH, DELETE
São utilizado de maneira semântica e não funcional (significado)

GET /users => Buscando um usuário no backend
POST /users => Criando um usuário no backend

Stateful = dados armazenado em memoria no node
Stateless = dados armazenador em terceiro (banco de dados)

Cabeçalhos (req,res) => Metadados (não necessariamente informações)

HTTP Status Code
Códigos númericos (semantica) para dizer ao front-end a situação da requisição(se deu erro, se está ok, se foi falta de info, etc)

middleware é um conceito de interceptadores (tradução), é uma função que intercepta a requisição
são identificados por receberem os parametros (req,res)

métodos sendo GET, POST, etc... & url sendo o caminho da requisiçao (/users por exemplo)

utilizaçao do postman para criar requisiçoes

Tipos de rotas

Query Parameters: URL Stateful => Filtros, paginação, não obrigatorios
Ex: http://localhost:3333/users?userID=1&name=Marlo

Route Parameters: Identificação de recursso
Ex: GET http://localhost:3333/users/1 => solicitando usuário de ID 1

Request Body: Envio de informações de formulário (HTTPs)
Ex: solicitações de objeto feitas no postman
