# Tipos de testes:

Unitarios: testa exclusivamente uma unidade da minha aplicação, uma pequena parte isolada
Integração: testa a comunicação entre duas ou mais unidades, duas partes da minha aplicação que se comunicam
E2E - ponta a ponta: simulam um usuário operando nossa aplicação; back-end: Chamadas HTTP, websockets (front-end)

# Pirâmide de testes:

E2E: não dependem de nenhuma tecnologia, não dependem de arquitetura, porem são menos performáticos
